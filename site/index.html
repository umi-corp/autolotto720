AutoLotto720(오토로또720)은 동행복권 연금복권720+를 정해 둔 요일과 시간에 매주 자동 구매하는 안드로이드 앱입니다. 목요일 추첨 뒤 당첨 여부를 확인해 알려드립니다.

조·번호 설정부터 당첨 알림까지 자동 처리

앱 실행 없이 정해 둔 시각에 구매와 당첨 확인을 진행하고 알림을 보냅니다

  1. 01

    조·번호 설정

    게임 A~E 최대 5매의 조와 6자리 번호를 매마다 수동으로 지정해 매주 고정하거나 자동으로 지정해 매주 새로 배정합니다

  2. 02

    자동 구매

    저장한 설정으로 지정 요일과 시간에 구매하며 기본값은 금요일 오전 9시이며 판매 정지 시간인 목요일 17:00~22:00는 제외합니다

  3. 03

    당첨 확인

    목요일 19:05 추첨 뒤 매주 목요일 21:00에 결과를 자동 확인하고 게임별 등수와 당첨금을 표시합니다

  4. 04

    알림

    구매 완료와 당첨 결과, 예치금 잔액 부족을 푸시 알림으로 알려드립니다

주요 기능

조와 번호부터 구매, 기록, 예치금까지 앱 한 곳에서 관리합니다

번호

슬롯별·모든조 세트

슬롯별로 게임마다 완전 자동, 조만 지정하는 번호 자동 배정, 조와 6자리 번호를 직접 입력하는 수동 중 선택하고 '전부 자동' 버튼으로 모든 게임을 자동 전환합니다. 모든조 세트는 1~5조에 같은 자동 번호로 1매씩 총 5매를 구매합니다(5,000원).

설정

자동 구매·예산 한도

구매 요일과 시간을 변경하고 예치금 잔액을 확인할 수 있으며 동행복권 충전 페이지로 이동할 수 있습니다. 1일 예산 한도와 회차 예산 한도는 기본값이 각 5,000원으로 초과 구매를 차단하며, 앱은 정시 실행을 위한 배터리 최적화 제외를 안내합니다.

  • 즉시 구매

    번호 탭에 저장한 게임을 바로 결제하며 이미 구매한 회차에는 자동 게임을 추가 구매합니다

  • 중복 결제 방지

    같은 회차의 중복 자동 구매를 차단하며 결제 결과 응답이 없을 때는 재시도 대신 구매 내역을 대조해 확인합니다

  • 구매 기록

    최근 3개월 기록을 자동 조회하고 '더 보기'로 최대 1년까지 조회하며 회차별 조·번호·등수·당첨금을 표시합니다

  • 잔액 부족 알림

    예치금 잔액이 기준 금액 이하일 때 하루 한 번 알림을 보내며 기준 금액은 5,000원·10,000원·20,000원 중 선택하거나 직접 입력하며 기본값은 5,000원

  • 앱 내 업데이트

    새 버전을 탭 한 번으로 설치하며 설치 전 패키지명과 서명을 검증합니다

  • 보안 저장

    계정 정보는 Android Keystore로 암호화해 기기 안에만 저장하고 동행복권 로그인에만 사용하며 자체 서버나 제3자 서버로 전송하지 않습니다

사용 방법

  1. 앱 설치

    이 페이지에서 APK를 다운로드해 설치하며 설치 시 '출처를 알 수 없는 앱' 허용이 필요합니다

  2. 동행복권 로그인

    설정 탭에서 동행복권 아이디와 비밀번호로 로그인합니다

  3. 조·번호 저장

    번호 탭에서 슬롯별 또는 모든조 세트를 선택한 뒤 조와 번호를 지정해 저장합니다

  4. 자동 구매 켜기

    설정 탭에서 자동 구매 활성화 후 매주 자동으로 구매합니다

자주 묻는 질문

AutoLotto720을 사용하려면 무엇이 필요한가요?

동행복권(dhlottery.co.kr) 회원 계정과 구매 금액만큼의 예치금이 필요하며 1매는 1,000원입니다. 예치금은 동행복권 홈페이지에서 충전하며 앱에서 충전 페이지로 이동할 수 있습니다.

동행복권 계정 정보는 안전한가요?

계정 정보는 Android Keystore로 암호화해 기기 안에만 저장하며 동행복권 로그인에만 사용합니다. 자체 서버는 없습니다. GitHub에 공개된 소스 코드에서 확인할 수 있습니다.

Google Play에는 왜 없나요?

Google Play 도박 정책상 복권 구매 앱을 등록할 수 없습니다. APK는 GitHub 릴리스로 배포하며 새 버전은 앱 안에서 업데이트할 수 있습니다.

한 회차에 몇 매까지 구매할 수 있나요?

동행복권 온라인 구매 한도는 회차당 5매(5,000원)입니다. 동행복권 서버가 한도 초과 여부를 판정하고 초과분을 거절합니다.

지정한 번호가 이미 판매된 경우 어떻게 처리하나요?

번호 탭에서 조와 번호 모두 자동 배정, 조 유지 후 번호 자동 배정, 구매 포기 중 처리 방식을 선택할 수 있습니다. 기본값은 조와 번호 모두 자동 배정입니다.

iPhone을 지원하나요?

Android 12 이상 전용이며 iPhone 앱은 없습니다.

앱을 열지 않아도 자동 구매가 되나요?

인터넷 연결 시 앱 실행 없이 지정 시각에 자동 구매하며, 정시 실행을 위해 배터리 최적화 제외를 권장합니다. 판매가 정지되는 목요일 17:00~22:00에는 구매 시간을 설정할 수 없습니다.

동행복권 공식 앱인가요?

동행복권 공식 앱이 아닌 UMI Corp에서 개발한 앱입니다. 사용에 따른 책임은 사용자에게 있습니다. 19세 미만은 복권을 구매할 수 없습니다.
